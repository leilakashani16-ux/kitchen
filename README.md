# سیستم مدیریت کترینگ – نسخه کامل Supabase

اپ چندکاربره واقعی با احراز هویت Supabase، پایگاه‌داده ابری، خروجی اکسل و PDF فارسی.

## فایل‌های ضروری

| فایل | کار |
|------|-----|
| `app.py` | اپ اصلی (وصل به Supabase) |
| `pdf_utils.py` | تولید PDF فارسی |
| `fonts/` | فونت وزیرمتن |
| `supabase_schema.sql` | ساخت جداول + RLS + View |
| `supabase_seed.sql` | داده‌های اولیه مهر ۱۴۰۵ |
| `requirements.txt` | وابستگی‌ها |

## راه‌اندازی کامل (۵ مرحله)

### ۱. ساخت پروژه Supabase
- بروید به [supabase.com](https://supabase.com) و یک پروژه رایگان بسازید.
- صبر کنید تا پروژه آماده شود.

### ۲. ساخت جداول
- در منوی چپ **SQL Editor** را باز کنید.
- محتوای کامل فایل `supabase_schema.sql` را کپی و **Run** کنید.

### ۳. وارد کردن داده‌ها
- باز هم در SQL Editor محتوای `supabase_seed.sql` را اجرا کنید.
- مواد، پرسنل، محصولات، ورودها و تولیدهای مهر ۱۴۰۵ وارد می‌شوند.

### ۴. ساخت کاربر مدیر
- به **Authentication → Users** بروید و یک کاربر با ایمیل خودتان بسازید (یا از صفحه ثبت‌نام اپ استفاده کنید).
- به **Table Editor → profiles** بروید.
- رکورد مربوط به کاربر خودتان را پیدا کنید و ستون `role` را به `admin` تغییر دهید.

### ۵. دیپلوی روی Streamlit Cloud
1. این پوشه را روی GitHub آپلود کنید.
2. به [share.streamlit.io](https://share.streamlit.io) بروید و ریپو را Deploy کنید.
3. در تنظیمات اپ (⋮ → Settings → Secrets) این دو خط را بگذارید:

```toml
SUPABASE_URL = "https://xxxxxxxxxxx.supabase.co"
SUPABASE_KEY = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...."
```

(مقادیر را از **Project Settings → API** در Supabase کپی کنید – از کلید `anon` `public` استفاده کنید)

4. Save و منتظر ریستارت بمانید.
5. وارد اپ شوید.

## نقش‌ها

| نقش | دسترسی |
|-----|--------|
| `admin` | همه چیز + مدیریت نقش کاربران |
| `inbound` | ثبت ورود مواد + ثبت ضایعات + گزارش |
| `production` | ثبت تولید + گزارش |
| `viewer` | فقط داشبورد و گزارش‌ها |

مدیر از منوی «مدیریت نقش‌ها» می‌تواند نقش هر کاربر را تغییر دهد.

## قابلیت‌ها

- ورود و ثبت‌نام با ایمیل (Supabase Auth)
- ثبت ورود مواد و ضایعات (کسر خودکار از موجودی)
- ثبت تولید با محاسبه خودکار وزن
- موجودی لحظه‌ای
- خروجی اکسل در تمام بخش‌ها
- خروجی PDF فارسی (موجودی و عملکرد پرسنل)
- گزارش‌های کامل

## نکات مهم

- اگر تأیید ایمیل در Supabase فعال باشد، بعد از ثبت‌نام باید لینک ایمیل را تأیید کنید.
- برای تست سریع می‌توانید در Authentication → Providers گزینه Confirm email را خاموش کنید.
- کلید `anon` برای کلاینت کافی است (امنیت با RLS کنترل می‌شود).
