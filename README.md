## گزینه ۲: استقرار با Supabase (پیشنهادی برای چندکاربره واقعی + Realtime)

### مراحل سریع:

1. بروید به [supabase.com](https://supabase.com) و یک پروژه رایگان بسازید.
2. از منوی **SQL Editor** محتوای فایل `supabase_schema.sql` را کامل اجرا کنید.
3. از **Authentication → Providers** ایمیل را فعال کنید (یا هر روشی که می‌خواهید).
4. از **Project Settings → API** مقادیر زیر را کپی کنید:
   - Project URL
   - `anon` `public` key
5. در Streamlit Cloud (یا محلی) این دو متغیر محیطی را تنظیم کنید:
   ```
   SUPABASE_URL=https://xxxx.supabase.co
   SUPABASE_KEY=eyJhbGciOi...
   ```
6. داده‌های اولیه (مواد، پرسنل، محصولات) را از اکسل یا از طریق Table Editor وارد کنید.

> **نکته:** نسخه فعلی اپ هنوز روی SQLite محلی کار می‌کند.  
> اگر بخواهید، نسخه کامل متصل به Supabase (با Auth حرفه‌ای Supabase) را در مرحله بعد می‌توانم جداگانه تحویل دهم.  
> اسکیما و RLS آماده است و Realtime را هم می‌توان فعال کرد.

### مزایای Supabase
- کاربران واقعی با ایمیل/رمز یا جادویی
- Realtime (تغییرات لحظه‌ای بین کاربران)
- پشتیبان‌گیری خودکار
- Row Level Security

## گزینه ۳: چاپ حرفه‌ای PDF

در داشبورد و بخش گزارش‌ها دکمه‌های **📄 دانلود PDF** اضافه شده است.

- گزارش موجودی با جدول کامل و وضعیت
- گزارش عملکرد پرسنل
- پشتیبانی کامل راست‌چین و فونت وزیرمتن

برای چاپ مستقیم از مرورگر هم دکمه «آماده‌سازی چاپ» وجود دارد (Ctrl+P).

## ساختار فایل‌ها

```
app.py                 → اپ اصلی Streamlit
pdf_utils.py           → تولید PDF فارسی
kitchen_management.db  → دیتابیس SQLite (با داده‌های مهر ۱۴۰۵)
supabase_schema.sql    → اسکیمای آماده برای Supabase
fonts/                 → فونت وزیرمتن
requirements.txt
README.md
```

## دیپلوی سریع روی Streamlit Cloud

1. ریپوی گیت‌هاب بسازید و همه فایل‌ها را آپلود کنید.
2. به [share.streamlit.io](https://share.streamlit.io) بروید.
3. ریپو را انتخاب و Deploy کنید.
4. چند کاربر همزمان می‌توانند وارد شوند (با SQLite محدودیت همزمان‌نویسی وجود دارد؛ برای استفاده جدی Turso یا Supabase توصیه می‌شود).
